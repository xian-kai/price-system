# 曜石云 · 岩板报价系统

面向岩板企业的销售及智能报价网站原型。当前版本包含经营首页、销售趋势、业务待办、产品排行，以及可交互的岩板材料、规格、损耗与定制加工报价计算器。

## 本地运行

项目无需构建步骤，使用任意静态文件服务器即可运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已规划模块

- 我的流程与审批待办
- 客户关系及客户跟进
- 报价单、报价管理、合同下单及合同管理
- 经营数据统计看板
- 产品、库存、定制工艺及计价规则配置
- 组织、角色、权限与系统参数管理
